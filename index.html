How it works: this page talks to your wallet directly (no server, no backend). It reads your Agent ID status from the SPACE ID Agent ID contract (0x60b9262456de011f7d15a54cdd8c48baaa8b022f) and sends one mint() transaction to the Agent Mint contract. You see and confirm the transaction yourself in your own wallet — this page never asks for your seed phrase or private key, and it never signs anything on your behalf. Built for the Binance Agent ID Hackathon.
